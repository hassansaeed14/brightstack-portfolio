Pulse — Guided Breathing

A low-fidelity wireframe set for a short breathing-exercise app, built as a tappable prototype rather than flat screens — so the core loop (start a session, breathe, see it logged) can be felt, not just described.

Deliverable — 4 wireframe screens Fidelity — low-fi, grayscale Prototype — tappable, animated Timeline — 3-day delivery
Tappable wireframe flow

Onboarding → session → breathing animation → logged streak. Still grayscale and rough on purpose, but wired together with real transitions so the pacing of the flow can be judged, not just the layout.

Onboarding → Session → Breathe → Logged

Tap the dots (or the dark block inside the phone) to move through the flow. Each transition uses the same slide-and-fade motion, so the rhythm of moving through the app is part of what's being tested, not just the screens themselves.
