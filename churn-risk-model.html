How this actually works

This page loads Pyodide — a real CPython interpreter compiled to WebAssembly — and runs actual Python in your browser tab. It's the same distinction the Smart Inquiry Router draws in reverse: that demo is honest about being rule-based, and this one is a genuine trained model.

  • 140 synthetic client records are generated with a fixed random seed (two features: engagement score, average payment delay).
  • Features are min-max normalized, then split 80/20 into train and test sets.
  • A logistic regression model is trained with batch gradient descent, implemented from scratch — no scikit-learn, no numpy, just loops and math.log/exp.
  • Every time you move a slider and click "Train," it re-runs actual gradient descent in Python, live, and reports real accuracy on data it never trained on.

Limitations, stated plainly: it's a two-feature linear model on a small synthetic dataset — a deliberately simple, inspectable example, not a production churn model.
