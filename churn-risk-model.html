This module mounts a standalone Python environment inside the client browser, executing compiled C code via WASM. It proves that client-side applications can handle rigorous mathematical computations locally without offloading tasks to remote compute clusters.

  • Data Pipeline: 180 synthetic enterprise customer rows generated across two parameters (engagement score, payment latency).
  • Normalization: Min-max feature scaling applied prior to train/test set splitting (80/20 ratio).
  • Optimization: Batch gradient descent calculated iteratively using fundamental math primitives (`math.log`, `math.exp`).
  • Live Execution: Parameter updates trigger immediate recompilation and forward/backward passes on unseen validation data.
