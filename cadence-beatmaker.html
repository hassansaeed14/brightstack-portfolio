Cadence — Browser Beat Sequencer

An eight-track step sequencer running entirely client-side via the Web Audio API. Features real-time synthesized voices, live FFT frequency spectrum analysis, swing timing offsets, velocity accents, and full mute/solo routing matrices.

Architecture — Desktop Web DAW Audio Engine — Web Audio API + AnalyserNode Routing — 8 Voices + Master Bus Engineering — Zero external audio samples
// 01. Synthesis Engine

Every transient is generated live through mathematical oscillators and white-noise buffers, completely avoiding static audio assets.

// 02. Spectral Analysis

The top frequency display reads live Fast Fourier Transform (FFT) data directly off the master bus output in real-time.

// 03. Groove Timing

A parameterized swing delay dynamically shifts off-beat sixteenth steps to emulate human micro-timing variations.

// 04. Signal Routing

Per-track mute and solo states interface precisely with master bus volume controllers for authentic mixing workflows.
