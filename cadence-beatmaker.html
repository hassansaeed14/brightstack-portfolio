Cadence — Browser Beat Sequencer

An eight-track step sequencer that runs entirely in the browser — real synthesized drums and synths, a live spectrum analyzer reading the actual audio output, swing, per-step accents, mute/solo, and preset patterns. Built to prove this studio can pair interface design with real front-end engineering, not just static comps.

Format — desktop web app Audio — real synthesis + live analysis Tracks — 8, with mute/solo Type — self-directed exploration
Sound engine

Every hit is synthesized live via the Web Audio API — no samples. Eight distinct voices, each with its own envelope and filtering.

Real analysis

The bar visualizer above the grid isn't decorative — it's an AnalyserNode reading actual frequency data from what's playing, in real time.

Groove control

A swing knob delays every off-beat step, the same feature that separates a stiff sequencer from one that grooves.

Real mix control

Per-track mute, solo, and volume, plus a master fader — the actual signal chain a mix engineer would expect, not just visual sliders.

Try it

Click a step once for a normal hit, twice for an accent (brighter, louder), a third time to clear it. Load a preset, drag the swing or master knobs, or mute/solo any track — then hit play.

Eight synthesized voices

Kick, snare, clap, closed hat, open hat, tom, bass synth, and lead synth — each built from oscillators, noise buffers, and filters tuned per-instrument, not one generic "click" sound reused eight times.

Three-state steps

Every cell holds more than on/off — a second click accents it, giving the pattern dynamics instead of a flat, mechanical grid.

A real mixing surface

Mute and solo interact properly — soloing one track silences the rest, the way an actual mixer behaves — and the master fader sits after every track in the signal chain, controlling the true output level.
