Design concept

A short note on the single direction this wireframe set is built toward — the concept a Basic-tier client walks away with, ready to hand to a visual designer or build on directly.

Direction: "one glance, one tap"

Every screen answers a single question without scrolling: what's due, what's done, what's next. No secondary navigation competes with the primary action on any screen.

Placeholder palette — color direction only, applied at the next fidelity pass.

Grid. 8pt spacing system carried across all four screens so nothing feels hand-placed.
Hierarchy. One dark block per screen marks the primary action — everything else recedes to a lighter fill.
Handoff-ready. Structured as named, numbered frames so a developer or designer can pick this up without a walkthrough call.
Figma file. Delivered as an editable file, not flattened images — every box is a real frame.
